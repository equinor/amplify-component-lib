## Usage

Chips allow users to enter information, make selections, filter content, or trigger actions.

<ul>
  <li>Chips are **compact** components that represent discrete information.</li>
  <li>Chips should be **relevant** to the content or task they represent.</li>

  <li>
    Chips should make tasks easier to complete, or content easier to sort.
  </li>
</ul>

## Accessibility

Don't rely on the `error` ("Danger") and `green` colors alone to convey opposite
meanings (e.g. failed vs. succeeded) — this combination is hard to distinguish for
people with red-green color blindness. Pair the color with an icon or a clear label
instead.
